# THE FOUNT Medical Location

병원 개원을 준비하는 원장님을 위한 지도 기반 AI 입지·상권 분석 웹앱입니다.

현재 버전은 실제 서비스 흐름과 화면을 검토하기 위한 Mock Data 기반 데모입니다. 주소 검색, 진료과·반경·기간 필터, 유동인구 타임라인, 경쟁병원 마커, 지역 점수, 진료과 추천, 3년 전망과 후보지 비교를 제공합니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 배포

Next.js 프로젝트로 구성되어 GitHub 연동을 통한 Vercel 자동 배포를 지원합니다.
